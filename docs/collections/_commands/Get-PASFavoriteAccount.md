# Get-PASFavoriteAccount

## SYNOPSIS
Gets favorite accounts

## SYNTAX

```
Get-PASFavoriteAccount [<CommonParameters>]
```

## DESCRIPTION
Gets the accounts marked as favorites by the current user.

Requires CyberArk Version 15.2 or higher.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-PASFavoriteAccount
```

Gets the favorite accounts of the current user
