# Get-PASDiscoveryScanSetting

## SYNOPSIS
Gets discovery scan settings

## SYNTAX

```
Get-PASDiscoveryScanSetting [<CommonParameters>]
```

## DESCRIPTION
Gets the discovery scan settings, including the available scanners.

Requires CyberArk Version 15.2 or higher.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-PASDiscoveryScanSetting
```

Gets discovery scan settings
