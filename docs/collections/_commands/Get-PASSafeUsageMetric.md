# Get-PASSafeUsageMetric

## SYNOPSIS
Gets safe usage metrics

## SYNTAX

```
Get-PASSafeUsageMetric [<CommonParameters>]
```

## DESCRIPTION
Gets counts of empty, unused, overloaded and total safes.

Requires CyberArk Version 15.2 or higher.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-PASSafeUsageMetric
```

Gets safe usage metrics
