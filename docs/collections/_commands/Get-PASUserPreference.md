# Get-PASUserPreference

## SYNOPSIS
Gets user preferences

## SYNTAX

```
Get-PASUserPreference [<CommonParameters>]
```

## DESCRIPTION
Gets the PVWA preferences of the current user, such as preferred layout and culture.

Requires CyberArk Version 15.2 or higher.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-PASUserPreference
```

Gets the preferences of the current user
