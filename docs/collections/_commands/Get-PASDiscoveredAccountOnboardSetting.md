# Get-PASDiscoveredAccountOnboardSetting

## SYNOPSIS
Gets discovered account onboarding settings

## SYNTAX

```
Get-PASDiscoveredAccountOnboardSetting [<CommonParameters>]
```

## DESCRIPTION
Gets the settings which apply when onboarding discovered accounts, including the safes available for onboarding.

Requires CyberArk Version 15.2 or higher.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-PASDiscoveredAccountOnboardSetting
```

Gets discovered account onboarding settings
