# Get-PASPSMSubnetRule

## SYNOPSIS
Gets PSM subnet rules

## SYNTAX

```
Get-PASPSMSubnetRule [<CommonParameters>]
```

## DESCRIPTION
Gets the PSM subnet rules and access policy.

Requires CyberArk Version 15.2 or higher.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-PASPSMSubnetRule
```

Gets the PSM subnet rules and access policy
