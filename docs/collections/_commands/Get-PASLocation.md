# Get-PASLocation

## SYNOPSIS
Gets vault locations

## SYNTAX

```
Get-PASLocation [<CommonParameters>]
```

## DESCRIPTION
Gets vault locations, with their quota and used quota.

Requires CyberArk Version 15.2 or higher.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-PASLocation
```

Gets vault locations
